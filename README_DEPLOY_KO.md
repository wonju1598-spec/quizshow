# QuizShow v2 배포 안내

## 이번 버전에서 바뀐 점
- 진행자: `/host`
- 참가자: `/join`
- 첫 화면의 진행자/참가자 선택 제거
- 진행자 비밀번호를 DB에 암호화하여 저장
- 퀴즈 문제/보기/정답/점수를 Render Postgres에 저장
- Render 서버가 재시작되어도 저장된 퀴즈가 남음
- 기존 Socket.IO 실시간 진행 기능 유지
- 정답 표시: 참가자 화면에서 초록색 빈 원(⭕)

## Render 설정
1. Render에서 Postgres 데이터베이스를 생성합니다.
2. 웹서비스의 Environment에 `DATABASE_URL`을 추가하고 Postgres의 연결 URL을 넣습니다.
3. GitHub에 이 프로젝트 파일을 업로드/교체합니다.
4. Render가 다시 배포되면 `https://내주소.onrender.com/host`로 들어갑니다.
5. 처음 한 번 진행자 비밀번호를 설정합니다.
6. 이후에는 그 비밀번호로 로그인하면 DB에 저장된 퀴즈를 불러옵니다.

비밀번호는 채팅이나 GitHub에 올리지 마세요.

주의: 현재 버전은 '퀴즈 데이터'를 영구 저장합니다. Render 서버가 재시작되는 순간 진행 중이던 방/참가자 연결 자체까지 복구하는 기능은 포함하지 않습니다. 서버가 재시작되면 진행자는 다시 방을 만들고 참가자는 새 방 코드로 입장해야 합니다.
